# iOS (Virtual)
Web-based iPhone-style OS. Open `index.html`.
Apps: Phone, Messages, Safari, Notes, Calendar, Photos, Camera, Weather, Clock, Calculator, Settings, Maps.
Add an app: push an object into `window.APPS` in `js/apps.js` ({id,name,bg,icon,render(el),close?(el)}).
Shortcuts: R rotate · H home/unlock · Esc back.
