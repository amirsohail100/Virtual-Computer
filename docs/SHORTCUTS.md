# Keyboard shortcuts

Browsers keep some keys for themselves (Ctrl+W, Ctrl+N, Ctrl+Q, the Windows key, Alt+Tab, Alt+F4), so the virtual systems use different combinations. The same lists are inside each OS: **Keyboard Shortcuts** app (Windows: Start → All apps, macOS: Help menu).

## Windows 11

`Ctrl+Alt+key` works like `Win+key`.

**System**

| Keys | Action | Real Windows |
|---|---|---|
| `Ctrl+Alt+S` | Open Start menu and search | Win+S |
| `Ctrl+Alt+E` | Open File Explorer | Win+E |
| `Ctrl+Alt+R` | Open the Run dialog | Win+R |
| `Ctrl+Alt+D` | Show / hide the desktop | Win+D |
| `Ctrl+Alt+L` | Lock the screen | Win+L |
| `Ctrl+Alt+I` | Open Settings | Win+I |
| `Ctrl+Alt+A` | Open Quick settings | Win+A |
| `Ctrl+Alt+N` | Open notifications and calendar | Win+N |
| `Ctrl+Alt+T` | Open Task View | Win+Tab |
| `Ctrl+Alt+K` | Open Task Manager | Ctrl+Shift+Esc |

**Windows**

| Keys | Action | Real Windows |
|---|---|---|
| `Ctrl+Alt+M` | Minimize all windows | Win+M |
| `Ctrl+Alt+W` | Close the active window | Alt+F4 |
| `Ctrl+Alt+↑` | Maximize the window | Win+↑ |
| `Ctrl+Alt+↓` | Restore, then minimize the window | Win+↓ |
| `Ctrl+Alt+←` | Snap the window to the left half | Win+← |
| `Ctrl+Alt+→` | Snap the window to the right half | Win+→ |

**File Explorer (click a window first)**

| Keys | Action |
|---|---|
| `F2` | Rename the selected item |
| `Delete` | Move the selected item to the Recycle Bin |
| `Enter` | Open the selected item |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copy, cut, paste |
| `Alt+N` | New folder |
| `Alt+Enter` | Properties |
| `F5` | Refresh |
| `Backspace` | Back |
| Right-click | New, View, Sort by, Group by, Properties |

**Other apps**

| App | Keys |
|---|---|
| Notepad | `Ctrl+S` saves the file |
| Calculator | Type digits and `+ - * /`, `Enter`, `Backspace` |
| Anywhere | `Esc` closes menus, Start and Task View |

## macOS

⌘ is `Alt` on a Windows keyboard. On a real Mac keyboard the ⌘ key works as well.

**General**

| Mac key | Press this | Action |
|---|---|---|
| `⌃Space` | `Ctrl+Space` | Spotlight search |
| `F4` | `F4` | Launchpad |
| `F3 / ⌃↑` | `F3 or Ctrl+↑` | Mission Control (see all windows) |
| `⌥⌘⎋` | `Ctrl+Alt+Esc` | Force Quit (Activity Monitor) |
| `⌃⌘Q` | `Ctrl+Alt+L` | Lock screen |
| `⌥⌘D` | `Ctrl+Alt+D` | Show / hide the Dock |

**App**

| Mac key | Press this | Action |
|---|---|---|
| `⌘N` | `Alt+N` | New window (or new note in Notes) |
| `⌘W` | `Alt+W` | Close window |
| `⌘M` | `Alt+M` | Minimize window |
| `⇧⌘M` | `Alt+Shift+M` | Minimize all windows |
| `⌘H` | `Alt+H` | Hide the current app |
| `⌘Q` | `Alt+Q` | Quit the current app |
| `⌘,` | `Alt+,` | Open System Settings |
| `⌘`` | `Alt+`` | Cycle windows of the same app |

**Windows**

| Mac key | Press this | Action |
|---|---|---|
| `⌃⌘F` | `Ctrl+Alt+F` | Zoom window (full size) |
| `⌃⌘←` | `Ctrl+Alt+←` | Move window to the left half |
| `⌃⌘→` | `Ctrl+Alt+→` | Move window to the right half |
| `⌃⌘C` | `Ctrl+Alt+C` | Center the window |

**Finder**

| Mac key | Press this | Action |
|---|---|---|
| `⇧⌘N` | `Alt+Shift+N` | New folder |
| `⌘⌫` | `Alt+Backspace` | Move to Trash |
| `Space` | `Space` | Quick Look the selected file |
| `⌘1 / ⌘2` | `Alt+1 / Alt+2` | View as icons / as list |
| `⌘[ / ⌘]` | `Alt+[ / Alt+]` | Back / forward |
| `⌘↑` | `Alt+↑` | Go to the enclosing folder |
| `⌘O` | `Alt+O` | Open the selected item |
| `⇧⌘D` | `Alt+Shift+D` | Duplicate |
| `⇧⌘F` | `Alt+Shift+F` | Search in Finder |

**Safari**

| Mac key | Press this | Action |
|---|---|---|
| `⌘L` | `Alt+L` | Go to the address bar |
| `⌘R` | `Alt+R` | Reload the page |
| `⌘[ / ⌘]` | `Alt+[ / Alt+]` | Back / forward |

**TextEdit**

| Mac key | Press this | Action |
|---|---|---|
| `⌘S` | `Alt+S (or Ctrl+S)` | Save the document |

**Calculator**

| Mac key | Press this | Action |
|---|---|---|
| `0–9 + − × ÷ ⏎` | `type on the keyboard` | Calculate with the keyboard |

**More**

| Feature | How |
|---|---|
| App switcher | Hold `Alt`, tap `J` (or `⌘Tab` on a Mac keyboard), release `Alt` to switch |
| Finder | `Enter` renames the selected item |
| Spotlight | Type a calculation such as `12*7` |

## Android

Click the phone first so it receives the keys.

| Key | Action |
|---|---|
| `R` | Rotate the phone (portrait / landscape) |
| `Esc` | Back |
| `H` | Home |
| `N` | Open the notification shade and quick settings |
| `Enter`, `Space` or `↑` | Unlock the lock screen |

Mouse gestures: click the status bar (or drag it down) for quick settings, drag up on the home screen for the app drawer, and click the lock screen to unlock.
