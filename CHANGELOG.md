# Changelog

## v0.5 — macOS
- Added `os/mac`: login screen, menu bar (Apple menu, app menus, status icons, clock), Dock with magnification, Launchpad, Spotlight, Control Center and Notification Center.
- 13 apps: Finder, TextEdit, Notes, Calculator, Safari-style browser, Calendar, Clock, Weather, Photos, Photo Booth, Terminal, Activity Monitor and System Settings.
- Three wallpapers (Waves, Dusk Hills, Ribbons) and custom wallpaper upload (Fill / Fit / Stretch / Center / Tile, drag and drop).
- Home page: the macOS card is now available.

## v0.4 — Virtual Computer
- Project renamed to Virtual Computer.
- New home page with OS cards (Windows, macOS, Android, iPhone).
- Windows 11 moved to `os/windows`; "Switch OS" added to the Windows power menu.

## v0.3 — Windows 11 polish
- Start menu and File Explorer redesigned.
- Custom wallpaper upload and eight new apps.
- Default pinned apps on the taskbar.

## v0.2 — Windows 11 look
- Bloom wallpaper, Windows 11 Start icon, tray panels (hidden icons, keyboard layout, quick settings, notifications and calendar).
- Right-click menus on the desktop and taskbar.

## v0.1 — First prototype
- Windows 11 style desktop with lock screen, window manager, Start menu and eight apps.
