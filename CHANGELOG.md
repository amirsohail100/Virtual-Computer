# Changelog

## v0.7.2 — Home page: Nokia 3310 and Quadra OS
- Coming-soon cards for the Nokia 3310 keypad phone and for Quadra OS (the author's own custom OS).
- LICENSE now covers the Nokia-style phone and the Snake game (education only) and names the Quadra projects.
- Footer text mentions Nokia.

## v0.7.1 — Android rotation and more apps
- The phone now turns by 90° like a real phone, then the screen settles into the landscape layout (before, only the shape changed).
- Nine new apps: Play Store (demo), Maps, Mail, Music, Files, Weather (demo), Contacts, Recorder and Snake. The phone now has 20 apps.
- Fixed invisible status and navigation bars in dark apps (Calculator, Camera) and a bright line at the edge of blurred screens.

## v0.7 — Android (basic)
- Added `os/android`: a phone inside the page with a lock screen, home screen, app drawer, recents, notification shade, quick settings and navigation buttons.
- **Landscape mode:** rotate button, `R` key and a quick settings tile. YouTube has an immersive full-screen player.
- 11 apps: Phone, Messages, Chrome, YouTube, Camera, Gallery, Settings, Clock, Calculator, Calendar, Notes.
- Three wallpapers (Bloom, Aurora, Dunes) and custom wallpaper upload; light and dark themes.
- Home page: the Android card is now available.

## v0.6 — Right-click menus, more macOS, keyboard shortcuts
**Windows**
- File Explorer rewritten: right-click menu inside any drive or folder (View, Sort by, Group by, **New**, Properties, Open in Windows Terminal, Open with Code, Show more options).
- **New** can create a Folder, Shortcut, Access Database, Bitmap image, Word, PowerPoint, Publisher, Text Document, Excel Worksheet or Compressed (zipped) Folder. The new item opens in inline rename mode.
- The desktop gets the same right-click menu; items created there appear as icons.
- Run dialog, Task View, show desktop, window snap (drag a title bar to a screen edge) and a Keyboard Shortcuts app.
- Calculator accepts keyboard input.

**macOS**
- Menu bar icon redrawn as a real apple.
- Ten new apps: Music, Messages, Mail, Maps, Contacts, Reminders, Stickies, Preview, App Store and Keyboard Shortcuts (23 apps in total).
- Mission Control, app switcher, Quick Look, window snap, Finder duplicate.
- Keyboard shortcuts (⌘ works as Alt on a Windows keyboard).

**Project**
- LICENSE states that the macOS part is also for education and learning only.
- README, ARCHITECTURE, SHORTCUTS and ROADMAP documents updated.
